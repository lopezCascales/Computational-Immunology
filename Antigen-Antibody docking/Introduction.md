
### Useful resources

    1. haddock-restraints: Tool to generate restraints to be used in haddock3.
[haddock-restraints] (https://www.bonvinlab.org/haddock-restraints/home.html)  

    2. haddock-runner: Tool to run large scale haddock3 simulations using multiple input molecules in different scenarios
[haddock-runner] (https://www.bonvinlab.org/haddock-runner/)   
 
    3. haddock-tools: Set of useful utility scripts developed over the years by the BonvinLab group members

    4. User manual: The online HADDOCK3 guide describing every aspects of the tool.
[HADDOCK best practice guide] (https://www.bonvinlab.org/software/bpg/)
[Nanobody-antigen modelling tutorial using a local version of HADDOCK3] (https://www.bonvinlab.org/education/HADDOCK3/HADDOCK3-nanobody-antigen/)  
[PowerFit and DisVis tutorials] (https://www.bonvinlab.org/education/Others/)
[Integrative modelling of the apo RNA-Polymerase-III complex from MS cross-linking and cryo-EM data](https://www.bonvinlab.org/education/HADDOCK24/RNA-Pol-III-2024/)
[BioExcel Summer School on Biomolecular Simulations 2022](https://www.bonvinlab.org/education/biomolecular-simulations-2022/)
[BioExcel Summer School on Biomolecular Simulations 2018](https://www.bonvinlab.org/education/biomolecular-simulations-2018/)
